# 四草大眾廟網站 UX 視覺重塑提案與修改報告
*(基於「不變動前後端架構」之前提設計)*

本報告旨在說明如何透過現代化前端開發技術，在**不變動原有的 Classic ASP 後端程式、資料庫邏輯，且不更換核心 Bootstrap 3 框架**的前提下，將「四草大眾廟網站」的用戶體驗（UX）與美學設計，重塑為類似「日本小野照崎神社」的優雅禪風與現代響應式體驗。

---

## 一、 核心改造策略（無痛覆寫技術）

為了確保網站系統的穩定性與低維護成本，我們採取了**「樣式覆寫與 DOM 阻斷」**的技術方案：
1. **不修改核心結構**：不需更動任何 ASP 程式碼，僅在公共頁首/頁尾模板中引入自訂的樣式表與腳本。
2. **本地對比沙盒**：已在本地建立包含 60 個完整 HTML 頁面的複本，並於右下角加入 **一鍵切換按鈕**，便於客戶直觀比對「修改前」與「修改後」的差異。
3. **記憶狀態瀏覽**：使用瀏覽器的 `localStorage` 機制，一旦開啟新版體驗，即使跳轉至其他子網頁，也會維持新版樣式。

## 二、 核心優化項目對照表

| 項目 | 原始舊版樣式 (四草大眾廟) | 禪風新版 UX (小野神社風格) | 帶給使用者的價值 |
| :--- | :--- | :--- | :--- |
| **視覺色調** | 刺眼的純白背景配上純黑文字，視覺較為生硬。 | 柔和的**暖米白色背景**（`#faf8f5`）搭配**深炭灰色文字**（`#2b2b2b`）。 | 降低長時間閱讀網頁的眼睛疲勞感，建立溫潤、平靜的文化氛圍。 |
| **品牌字體** | 採用預設無襯線字型，字距過於擁擠。 | 引進 Google Fonts 的 **思源宋體**（標題）與**思源黑體**（內文），加寬字距與行高。 | 提升繁體中文的排版質感，營造如同藝術博物館般的文化底蘊。 |
| **版面呼吸感** | 各區塊上下間距較窄，資訊密度大、有壓迫感。 | 大幅拉開區塊上下間距（Padding 提高至 90px）。 | 創造精緻的「留白美學」，讓資訊呈現更有層次、不擁擠。 |
| **主視覺 (Hero)** | 疊加在輪播大圖上的是沉重、黑壓壓的巨型灰色標題背景方框。 | **完全透明背景**，文字改為輕盈白色宋體，搭配精緻文字陰影（Text Shadow），置中懸浮。 | 移除了視覺阻礙，讓美麗的綠色隧道大圖完整呈現，畫面更具電影張力。 |
| **首頁標題強調** | 原本的「四草大眾廟」為一般的白粗體字。 | 改為高雅的 **廟宇燕尾金**（`#dfba73`）並加入細緻底線。 | 彰顯宮廟文化的尊榮感，使視覺焦點瞬間鎖定在品牌名稱上。 |
| **最新消息列表** | 條列式文字排版，並使用老舊的漸層遮罩圖（`mask.png`）。 | 現代 **乾淨白色微陰影卡片式網格**。Hover 時卡片會輕微上浮、圖片微微放大。 | 提供直觀的資訊卡片閱讀體驗，滑鼠懸浮時的微互動讓網頁「活了過來」。 |
| **按鈕設計** | 舊式 Bootstrap 實色塊按鈕（綠色/橘色）。 | 精緻的 **墨綠細邊框 outline 按鈕**，滑鼠懸浮時會以墨綠色平滑填滿。 | 去除廉價模板感，細緻的框線按鈕能讓使用者更願意進行點擊互動。 |
| **手機版導航欄** | 黑底配上黑字，選單展開後文字幾乎無法閱讀。 | 全面**「光亮化」**（米白底、深灰字、森林綠強調色），高對比配色。 | 徹底解決手機端看不清字的問題，呈現如同日本神社般的乾淨清爽。 |
| **手機版選單圖示** | 右上角是通用的「漢堡三橫線」灰色按鈕。 | 改為客製化的 **「台灣傳統廟宇燕尾脊」向量 SVG 圖示**，並於下方標示「MENU」。 | 將在地文化特色融入 UI 中（仿小野神社的鳥居按鈕），圖示加文字也更具指引性。 |
| **功能去蕪存菁** | 頂部導航欄保留了無法運作或不常用的放大鏡搜尋按鈕。 | 在新版模式下，以 JS 與 CSS **完全隱藏搜尋圖示**。 | 簡化行動端介面，讓使用者的視覺焦點集中在 LOGO 與主導航上。 |
| **加載效能** | 載入重型的 Google Maps JavaScript SDK，導致手機瀏覽嚴重延遲。 | 改用 Google Maps Iframe 並設定 **延遲載入 (`loading="lazy"`)**。 | 大幅降低初次載入時的白屏等待時間，提升搜尋引擎（SEO）的評分。 |

## 三、 本地測試指引

您可以使用任何電腦瀏覽器，開啟您專案目錄下的 `4grass_clone/index.html` 進行對比展示：

1. **初始狀態**：網頁會預設載入「原始四草樣式」。
2. **點擊體驗**：點擊網頁右下角的懸浮按鈕 **「原始四草樣式 🔘」**。
3. **瞬間蛻變**：按鈕會轉為 **「✨ 體驗：小野日系禪風 UX」**，網頁字體、配色、留白、卡片、首頁主視覺將會在一瞬間套用新版美學。
4. **跨頁對比**：您可以點擊最新消息、交通資訊等頁面，切換器會記住狀態，讓您全程在新版樣式下瀏覽，也可以隨時切回舊版向客戶演示巨大的 UX 落差。
